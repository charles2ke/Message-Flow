MessageFlow

A small, dependency-free chain of responsibility library — one API, four server-side languages.

GitHub openapi.yaml Playground

Supported languages

  • C#

    .NET 8, ValueTask-based.

    dotnet add package MessageFlow
    Documentation

  • Java

    Java 17, CompletionStage-based.

    io.github.messageflow:messageflow
    Documentation

  • Python

    Python 3.9+, asyncio-based.

    pip install messageflow
    Documentation

  • Node

    Node 20+, TypeScript, Promise-based.

    npm install messageflow
    Documentation
